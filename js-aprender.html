¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar comportamiento e interacción a las páginas web.

HTML define la estructura, CSS define la apariencia y JavaScript permite que los elementos reaccionen a las acciones del usuario. 

const nombre = "Sebastián";

console.log(nombre);

💡 Pensalo así

HTML sería la estructura, CSS el diseño y JavaScript la lógica y el comportamiento.

TEMA 02

Variables

Las variables permiten guardar información que podemos utilizar posteriormente dentro de nuestro programa. 

let edad = 26;

const nombre = "Sebastián";

let activo = true;

💡 let y const

let se utiliza cuando el valor puede cambiar.

const se utiliza cuando no necesitamos reasignar la variable.

TEMA 03

Condicionales

Los condicionales permiten que nuestro programa tome decisiones dependiendo de una condición. 

const edad = 18;

if (edad >= 18) {
    console.log("Es mayor de edad");
} else {
    console.log("Es menor de edad");
}

TEMA 04

Funciones

Las funciones permiten agrupar instrucciones para poder reutilizarlas cuando las necesitemos. 

function saludar() {

    console.log("Hola");

}

saludar();

💡 ¿Por qué utilizarlas?

Nos ayudan a organizar el código y evitar repetir las mismas instrucciones.

Eventos

Los eventos permiten ejecutar código cuando ocurre una acción, como hacer clic en un botón. 

const boton =
    document.querySelector("button");

boton.addEventListener("click", function() {

    alert("Hola");

});

TEMA 06

DOM

El DOM permite que JavaScript pueda acceder y modificar los elementos HTML de una página. 

const titulo =
    document.querySelector("h1");

titulo.textContent =
    "Nuevo título";

💡 Acá empieza la interacción

Gracias al DOM podemos cambiar textos, clases, estilos y contenido de una página utilizando JavaScript.
