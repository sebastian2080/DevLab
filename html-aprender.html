TEMA 01

¿Qué es HTML?

HTML es el lenguaje utilizado para definir la estructura y el contenido de una página web.

HTML significa HyperText Markup Language. No es un lenguaje de programación: es un lenguaje de marcado que utiliza elementos para organizar y dar significado al contenido.

La mayoría de los elementos se escriben con una etiqueta de apertura, contenido y una etiqueta de cierre. Por ejemplo: 

<h1>Hola mundo</h1>
<p>Mi primera página web.</p>

Partes de un elemento HTML 

<p>Hola mundo</p>
 ↑              ↑
 apertura       cierre

También existen atributos que agregan información o configuración a un elemento. Por ejemplo, el atributo href indica la dirección de destino de un enlace. 

<a href="https://ejemplo.com">
    Visitar sitio
</a>

TEMA 02

Estructura de una página HTML

Una página HTML no es solamente un conjunto de etiquetas. Tiene una estructura básica que permite al navegador interpretar correctamente el documento.

Las partes principales son <html>, <head> y <body>. 

<!DOCTYPE html>

<html lang="es">

    <head>
        <meta charset="UTF-8">
        <title>Mi página</title>
    </head>

    <body>

        <h1>Hola mundo</h1>
        <p>Mi primera página web.</p>

    </body>

</html>

🔎 ¿Qué hace cada parte?

<html> contiene todo el documento.

<head> contiene información sobre la página que no forma parte del contenido visible.

<body> contiene todo lo que el usuario ve en la página.

TEMA 03

Títulos y párrafos

Una de las primeras cosas que aprendemos en HTML es cómo organizar el texto de una página.

Para los títulos utilizamos las etiquetas <h1> a <h6>. El <h1> representa el título principal y los demás niveles sirven para organizar subtítulos.

Para los párrafos utilizamos la etiqueta <p>. 

<h1>Mi página web</h1>

<h2>Sobre nosotros</h2>

<p>
    Esta es una página creada con HTML.
</p>

💡 Algo importante

No conviene elegir un título simplemente porque se ve más grande. Los niveles de encabezado representan la jerarquía del contenido.

Una estructura habitual es comenzar con <h1> y utilizar <h2> y <h3> para las secciones y subsecciones.

TEMA 04

Enlaces

Los enlaces son una de las partes fundamentales de la Web. Permiten conectar una página con otra, acceder a archivos, visitar otros sitios o incluso ir a una sección específica de la misma página. :contentReference[oaicite:0]{index=0}

Para crear un enlace utilizamos la etiqueta <a>. Su atributo más importante es href, que indica hacia dónde debe dirigir el enlace. :contentReference[oaicite:1]{index=1} 

<a href="https://www.ejemplo.com">
    Visitar sitio
</a>

💡 Enlaces dentro de tu proyecto

También podemos utilizar rutas relativas para conectar diferentes archivos HTML de nuestro propio proyecto. 

<a href="contacto.html">
    Ir a contacto
</a>

Incluso podemos enlazar directamente a una sección de la misma página utilizando un id. 

<a href="#contacto">
    Ir a contacto
</a>

<h2 id="contacto">
    Contacto
</h2>
🎥

TEMA 05

Imágenes

Las imágenes permiten agregar contenido visual a una página web. Para incorporarlas utilizamos la etiqueta <img>.

A diferencia de muchas etiquetas HTML, <img> no necesita una etiqueta de cierre. Para funcionar, normalmente utilizamos los atributos src y alt. :contentReference[oaicite:0]{index=0} 

<img
    src="imagen.jpg"
    alt="Descripción de la imagen"
>

💡 ¿Qué significa cada atributo?

src indica la ubicación de la imagen que queremos mostrar.

alt proporciona un texto alternativo que describe la imagen y es importante para la accesibilidad. :contentReference[oaicite:1]{index=1} 

<img
    src="images/foto.jpg"
    alt="Una computadora sobre un escritorio"
    width="400"
>

⚠️ Un detalle importante

No deberíamos utilizar imágenes que tengan derechos de autor sin tener permiso para hacerlo. Para proyectos reales, conviene utilizar imágenes propias o recursos con una licencia que permita su uso. :contentReference[oaicite:2]{index=2}

🎥

TEMA 06

Listas

Las listas permiten organizar información de una forma clara y fácil de leer. En HTML podemos crear listas sin orden, listas ordenadas y también listas anidadas.

Listas no ordenadas

Utilizamos <ul> cuando el orden de los elementos no es importante. Cada elemento se coloca dentro de una etiqueta <li>. :contentReference[oaicite:0]{index=0} 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Listas ordenadas

Utilizamos <ol> cuando el orden de los elementos sí tiene importancia, por ejemplo para explicar una serie de pasos. :contentReference[oaicite:1]{index=1} 

<ol>
    <li>Crear el archivo HTML</li>
    <li>Agregar el contenido</li>
    <li>Abrirlo en el navegador</li>
</ol>

💡 ¿Cuál debería usar?

Si cambiar el orden de los elementos no cambia su significado, normalmente utilizamos <ul>.

Si el orden sí importa, utilizamos <ol>. :contentReference[oaicite:2]{index=2}

Listas anidadas

También podemos colocar una lista dentro de otra. Esto resulta útil cuando tenemos categorías y subcategorías. 

<ul>

    <li>
        Desarrollo Web

        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>

    </li>

</ul>
🎥
