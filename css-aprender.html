TEMA 01

¿Qué es CSS?

CSS es el lenguaje que utilizamos para definir la apariencia y presentación de una página web.

Mientras HTML se encarga de la estructura, CSS nos permite modificar colores, tamaños, espacios, posiciones y mucho más. 

h1 {
    color: blue;
    font-size: 40px;
}

💡 HTML + CSS

HTML define qué elementos existen. CSS define cómo se ven esos elementos.

TEMA 02

Selectores

Los selectores permiten indicar qué elementos HTML queremos modificar mediante CSS. 

p {
    color: red;
}

.titulo {
    font-size: 30px;
}

#principal {
    background-color: black;
}

💡 Los tres más importantes

Elemento: selecciona etiquetas como p, h1 o div.

Clase: utiliza .nombre.

ID: utiliza #nombre.

TEMA 05

Box Model

El Box Model explica cómo CSS calcula el espacio que ocupa cada elemento. 

.card {
    width: 300px;
    padding: 20px;
    border: 1px solid black;
    margin: 20px;
}

📦 Sus cuatro partes

Contenido → padding → border → margin.

TEMA 06

Flexbox

Flexbox es una herramienta de CSS que permite organizar elementos de forma flexible dentro de un contenedor. 

.contenedor {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

💡 Lo vamos a usar mucho

Flexbox es especialmente útil para crear layouts, menús, tarjetas y componentes responsive.
